# Quickstart

Use this guide with Sythoria Desktop **v0.4.2**. The release currently provides the following builds:

| Operating system  | Supported build       | Release artifact                |
| ----------------- | --------------------- | ------------------------------- |
| Windows 10 or 11  | x64                   | `Sythoria_0.4.2_x64-setup.exe`  |
| macOS 12 or later | Apple silicon (arm64) | `Sythoria_0.4.2_aarch64.dmg`    |
| Linux             | x86_64/amd64 AppImage | `Sythoria_0.4.2_amd64.AppImage` |

Windows ARM64, Linux ARM64, and Intel macOS packages are not present in this release. Check the [current GitHub release](https://github.com/sythoria/sythoria-desktop/releases/latest) before installing because the artifact matrix can change.

## Connect a model

1. Open Sythoria and select **Settings**.
2. Add a model and select a provider preset.
3. Confirm the API base and default model. Provider defaults are listed below and can be changed.
4. Paste the provider API key. Sythoria stores provider keys through the operating system keychain.
5. Save the model and wait for the connection check.
6. Start a new conversation, select the model, and send a short test message.

Hosted-provider requests leave your device and are processed under that provider's terms. For a local model path, install Ollama and follow the [Ollama guide](/docs/providers/ollama).

## Verify the setup

A successful setup has all three of these results:

- the configured model reports a healthy connection;
- a new conversation can stream a short response; and
- reopening Sythoria retains the model configuration without asking you to paste the key again.

If one step fails, copy the error **after checking that it contains no key, prompt, local path, or personal data**, then use [Troubleshooting & Logs](/docs/features/logging-troubleshooting).

## Undo or reset

Remove a model from Settings to delete its configuration and associated credential. Use the application's deletion controls for conversations and projects; do not delete application-data files while Sythoria is running.
