# Motion & Reduced Motion

Sythoria uses short transitions to explain opening, closing, selection, and layout changes. Motion is cosmetic; it should not be required to understand or complete a task.

## Reduced motion

When the operating system requests reduced motion, the interface should replace long or repeating movement with stable states and near-instant transitions. This includes decorative particles, pulsing indicators that do not represent live status, parallax, and autoplay demonstrations.

The application and website must implement this behavior explicitly. The audited source does not support claims about automatic FPS measurement, `hardwareConcurrency` tiers, or a guaranteed frame rate, so those mechanisms are not part of this contract.

## Report a problem

Include the operating system, reduced-motion setting, Sythoria version, and the screen where motion continues. A short recording can help, but check it for private prompts, paths, notifications, and account details before sharing.

Motion that lasts more than a few seconds should have a pause/stop path or settle into a static state. Focus, keyboard operation, and content order must remain identical when animation is disabled.
