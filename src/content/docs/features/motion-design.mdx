# Motion & Reduced Motion

Sythoria uses short transitions when panels, menus, messages, and other interface elements change.

Open **Settings > Appearance** and turn off **App Animations** to disable interface transitions throughout the app. This preference is stored with the other application preferences.

## Reduced motion

When the operating system requests reduced motion, Sythoria removes movement and scale changes from its shared transitions and shortens them to 160 milliseconds. Its stylesheet also reduces CSS animation and transition durations to 0.01 milliseconds, runs animations once, and disables smooth scrolling.

Turning off **App Animations** is stricter: shared transitions use a duration of zero. Sythoria does not use automatic FPS measurement or hardware tiers to choose an animation mode.

## Report a problem

If animation continues after you turn it off, include the operating system, Sythoria version, and the affected screen in the report. A short recording can help, but check it for private prompts, paths, notifications, and account details before sharing.
