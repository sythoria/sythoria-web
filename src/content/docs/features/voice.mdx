# Voice Input & Transcription

## How Voice Transcription Works

Sythoria processes voice input on your device through a multi-stage local pipeline:

1. **Mic Capture**: Captures raw PCM audio from your default input device.
2. **Silero VAD (Voice Activity Detection)**: Filters background silence and detects active speech bounds to minimize processing overhead.
3. **Audio Resampling**: Converts the raw audio stream into mono 16kHz, 16-bit WAV format.
4. **Whisper Engine Inference**: Runs local model inference using `whisper-rs` (`whisper.cpp`) to transcribe speech into text and feeds it directly into your chat prompt.

## Local transcription

1. Open **Settings** and find the Whisper/voice section.
2. Download one of the model sizes offered by the current application.
3. Grant microphone permission when the operating system asks.
4. Select the downloaded model as the transcription path.
5. Record a short test and review the text before sending it to a chat model.

Local transcription keeps the recorded audio on the local processing path, but the resulting text can still leave the device when you send it to a hosted model.

The audited build uses `whisper-rs`. It does not configure or promise CUDA/CoreML acceleration in the documented package. Do not install a CUDA version solely for Sythoria unless a future release explicitly ships and documents that backend.

## Cloud transcription

A cloud endpoint receives the recorded audio and associated request metadata. Configure it only after reviewing the service's authentication, region, retention, and billing terms. Use a separate scoped key where the provider supports one.

## Permissions and storage

- Denying microphone permission prevents recording but should not affect text chat.
- Downloaded model files consume local disk space and can be removed from the voice settings.
- Recordings and transcripts can contain private speech, names, and background audio. Review them before attaching or sending.
- Headsets, sample rates, background noise, language, and model size affect transcription quality.

## Troubleshooting

| Symptom                  | Check                                                             |
| ------------------------ | ----------------------------------------------------------------- |
| No input                 | Operating-system microphone permission and selected input device  |
| Model unavailable        | Download completion, free disk space, and selected model          |
| Slow local transcription | Choose a smaller model and close memory-intensive applications    |
| Cloud 401/403            | Endpoint, key, region, and account permission                     |
| Poor transcript          | Input level, background noise, language, and a larger local model |

Revoke any cloud key that appears in an error message or screenshot before sharing diagnostics.
