# Multi-Model Comparison

Comparison mode shows the active conversation beside one or more comparison conversations. Each column can use a different configured model.

## Start a comparison

1. Open a conversation.
2. Press `Ctrl+Shift+C` or use the comparison control in the chat header.
3. Use the plus button to add columns.
4. Choose a model in each column.
5. Send the next prompt.

Sythoria starts the model requests concurrently. Network scheduling and provider queues mean they will not begin or finish at exactly the same time.

## Column behavior

When a column is added, it receives a copy of the current conversation messages and project selection. Changing a column's model affects that comparison conversation. Model settings such as temperature, context size, and reasoning level come from the selected model configuration.

The header can synchronize scrolling across columns. Each non-primary column can also be removed. Retry actions operate on the conversation in that column.

There is no enforced four-column limit in v0.4.4. The interface also does not calculate time to first token, tokens per second, or token-cost metrics.

## Provider boundaries still apply

Every selected hosted provider receives the prompt and the context assembled for its column. Comparing a local model with a hosted model does not keep the hosted column local. Check provider pricing and data terms before sending private material to several services at once.

If a comparison conversation has pending workspace changes, apply or discard them before leaving comparison mode.
