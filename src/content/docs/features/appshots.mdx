# Vision & Screenshots (Appshots)

Appshots captures a selected screen region and makes it available as conversation context. Review the capture before sending: it can contain notifications, keys, source code, names, email addresses, or other applications.

## Default shortcut

Sythoria v0.4.3 uses **Alt+Shift+S** on desktop platforms. The combination is configurable in the audited application store and can conflict with an operating-system or application shortcut.

1. Start Sythoria and select a vision-capable model.
2. Press **Alt+Shift+S**.
3. Select only the region required for the question.
4. Inspect the resulting image and remove it if private content is visible.
5. Send it only after confirming the configured provider and its image/privacy terms.

## Permissions

The operating system can require screen-recording/capture permission. Denying it should leave ordinary text chat available. If permission was denied permanently, use the operating system's privacy settings to review the Sythoria entry rather than broadly weakening screen-capture controls.

## Data path

Capture begins locally. When the screenshot is included in a request to a hosted model, the image and associated conversation context leave the device and are processed by that provider. A local vision model can keep model inference on the configured local endpoint, subject to any other enabled tools.

## Troubleshooting

| Symptom                | Check                                                          |
| ---------------------- | -------------------------------------------------------------- |
| Shortcut does nothing  | Shortcut conflict and whether Sythoria is running              |
| Selection cannot start | Operating-system screen-capture permission                     |
| Wrong display/scale    | Multi-monitor scale settings and current release issue tracker |
| Model rejects image    | Model modality and provider attachment limits                  |

Delete unwanted captures through the application flow and review normal operating-system backups separately.
