# Appshots

An Appshot captures the frontmost application window other than Sythoria. It does not provide a region-selection tool.

## Capture a window

1. Select a model that accepts image input.
2. Bring the window you want to capture to the front.
3. Press `Alt+Shift+S`.
4. Confirm that Sythoria may capture the frontmost application.
5. Check the image in the chat draft before sending it.

The default shortcut can be changed under **Settings > Keyboard Shortcuts**. The operating system may ask for screen-capture permission the first time you use it.

## Storage settings

Appshots can be saved as PNG or JPEG. JPEG quality is configurable. Saving to the Appshots gallery is off by default; when it is off, the capture is stored as an ephemeral file long enough to attach it to the draft.

If gallery saving is enabled, Settings also provides a capture folder and cleanup rules based on file count, total size, or age. The default cleanup rule keeps the most recent 50 captures.

## What leaves the device

Capture happens locally. The image leaves the device when you send it to a hosted model. The provider receives the image with the prompt and any conversation context included in that request.

Before sending, check for notifications, API keys, email addresses, private source code, and content from other applications.

## If capture fails

| Problem               | What to check                                                |
| --------------------- | ------------------------------------------------------------ |
| Nothing happens       | Sythoria is running and no other app owns the shortcut       |
| Permission denied     | Screen-recording permission in the operating system settings |
| Wrong window captured | The intended application was frontmost when you confirmed    |
| Image is rejected     | The selected model is marked as supporting image input       |
| Draft is full         | A message can contain no more than six attachments           |
