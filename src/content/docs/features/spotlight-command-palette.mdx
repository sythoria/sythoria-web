# Settings Search & Command Palette

Sythoria has three keyboard search tools. They open different parts of the app.

## Settings search

Press `Ctrl+Space` to bring Sythoria to the front and open the settings search. Start typing a section name such as Models, Privacy, Appshots, or MCP. Use the arrow keys to move through the results and press `Enter` to open a section.

This search does not send a prompt to a model. It only navigates the Settings screen.

`Ctrl+Space` is registered as a system-wide shortcut in v0.4.4. It is currently fixed and does not appear in the keyboard-shortcut editor.

## Command palette

Press `Ctrl+Shift+P` while Sythoria is focused. The palette can run these commands:

- start a new conversation;
- open Settings or Project Workspaces;
- turn web search or the current theme on and off;
- zoom in, zoom out, or reset zoom;
- create a project; and
- check for application updates.

The command palette shortcut can be changed under **Settings > Keyboard Shortcuts**.

## Conversation picker

`Ctrl+K` opens the conversation picker. It does not open the command palette. Use it when you know part of a conversation title and want to switch without browsing the sidebar.

## Shortcut conflicts

An operating system or another application can claim the same shortcut. If `Ctrl+Space` does nothing, confirm that Sythoria is running and check the operating system's global shortcut settings. Other Sythoria shortcuts can be changed in the app.
