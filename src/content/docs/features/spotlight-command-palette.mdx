# Spotlight & Command Palette

Sythoria Desktop is designed for maximum productivity and keyboard-driven efficiency. It includes a **Spotlight Floating Window** for rapid one-shot AI prompts from anywhere on your operating system, and a **Global Command Palette** for instantaneous navigation and setting toggles.

---

## Spotlight Floating Window

The **Spotlight Window** is a lightweight, floating search-bar interface that stays hidden in the background until triggered by a global system hotkey.

- **Global Hotkey**: Press `Option` + `Space` (macOS) or `Alt` + `Space` (Windows/Linux) from any application.
- **Instant Prompting**: Type a quick question, code query, or translation request without switching out of your current IDE or web browser.
- **Fast Execution**: Stream answers instantly, copy results to your clipboard with `Enter`, or hit `⌘` + `Shift` + `O` to promote the conversation to the full Sythoria main window.

## Global Command Palette (`⌘K` / `Ctrl+K`)

The **Command Palette** brings quick actions to your fingertips inside the main application window. Press `⌘K` (macOS) or `Ctrl+K` (Windows/Linux) to open the palette:

### Command Palette Actions

| Category            | Shortcut Action                | Description                                                        |
| :------------------ | :----------------------------- | :----------------------------------------------------------------- |
| **Navigation**      | `Go to Settings`               | Jump directly to settings sections (Models, Skills, Privacy, MCP). |
| **Model Selection** | `Switch Active Model`          | Rapidly switch between pre-configured LLM provider models.         |
| **Workspaces**      | `Mount Workspace`              | Open a local repository directory as an active project workspace.  |
| **Conversations**   | `New Thread` / `Clear History` | Start a new chat or search previous conversation history.          |
| **Themes**          | `Toggle Theme`                 | Switch between Dark Mode, Light Mode, and Glassmorphism themes.    |

---

## Customizing Keyboard Hotkeys

All hotkeys and shortcuts are fully customizable under **Settings > Keyboard Shortcuts**.

You can remap the Spotlight activation shortcut, Command Palette launcher, model toggles, and sidebar navigation keys to fit your preferred workflow.
